# Biblioteca en onda corta

Reseñas de cuentos en audio de la sala infantil de la Biblioteca Pública del Maule.

## Cómo agregar una reseña
1. Sube el audio (MP3) a la carpeta `audios/`, con un nombre simple, por ejemplo `elmer.mp3`.
2. En `index.html`, busca la lista `RESENAS` y añade o edita una entrada con `f` (frecuencia), `t` (título), `a` (autor), `d` (reseña) y `audio` (por ejemplo `audios/elmer.mp3`).
3. Guarda los cambios (commit). GitHub Pages actualiza el sitio en unos minutos.
